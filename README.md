
# AI Fluency Tasks

A collection of hands-on tasks and practical exercises completed as part of AI Fluency Training. This repository explores the fundamentals of AI, prompt engineering, LLM applications, tool usage, Retrieval-Augmented Generation (RAG), and agentic workflows.

## 📌 About the Project

The goal of this repository is to build a practical understanding of AI systems by implementing concepts through Python programs, experiments, and documentation.

It includes daily training tasks, code examples, configuration files, and experiments designed to explore how AI-powered applications work.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/roshniaru/AI_FLUENCY_TASKS.git
```

### 2. Navigate to the project directory

```bash
cd AI_FLUENCY_TASKS
```

### 3. Navigate to a specific task

For example:

```bash
cd day1_task
```

Choose the appropriate task directory based on the exercise you want to run.

### 4. Set up Python

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install dependencies

If the selected task contains a `requirements.txt` file, install its dependencies:

```bash
python -m pip install -r requirements.txt
```

### 6. Configure environment variables

Some tasks may require API credentials or model configuration.

Create a `.env` file if required by the task, and add the necessary variables according to its configuration instructions.

**Important:** Never commit API keys, passwords, or other secrets to GitHub.

### 7. Run the program

Follow the instructions provided in the relevant task directory. For Python scripts, use:

```bash
python filename.py
```

Replace `filename.py` with the actual script name.
